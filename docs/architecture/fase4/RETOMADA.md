# Retomada para gravação e PDF

1. Abra este dossiê, relatórios Cucumber/JaCoCo e capturas do New Relic. Eles preservam as provas de hoje sem exigir novos pagamentos.
2. Se for demonstrar a API ao vivo, inicie o AWS Academy e renove AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY e AWS_SESSION_TOKEN nos Secrets centralizados da organização. Verifique se os nós/serviços estão prontos. Não disparar apply/deploy por rotina só para gravar.
3. Para conferir registros existentes, use a collection 06 local e o environment privado. OS 09 e 11 estão entregues; OS 07/10 compensadas. Para OS 11, use os IDs do [BDD](BDD.md), sem substituir os IDs principais das collections sem necessidade.
4. Ensaiar o vídeo em até 15 minutos: arquitetura; fluxo; Saga/falha; CI/deploy aprovado; trace/logs/métricas. Identificar o que é registro anterior e o que está sendo executado ao vivo. Não mostrar valores de tokens/senhas.
5. Preencher o PDF com participantes/IDs, links dos repos e vídeo, diagrama e justificativas. O [texto de arquitetura](ARQUITETURA-E-SAGA.md) e a [matriz](ACEITE-E-ENTREGA.md) servem de fonte. Vídeo e PDF ficaram para o solicitante, não foram gerados/publicados nesta consolidação.
